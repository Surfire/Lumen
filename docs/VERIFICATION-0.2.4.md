# Lumen 0.2.4 核验

- 40 项 Rust 和 CLI 常规测试、1 项真实 Gemma 集成测试、10 项扩展测试、Clippy 和格式检查通过。原生签名资源、驻留启动和 11 组隔离 GUI 通过。
- 4 页设置的菜单快捷键、目录变更草稿、保存排除规则、按原范围维护、真实单文件诊断和两种外观已在合成索引上检查。选择文件使用应用内注入，诊断走真实 CLI；云盘占位使用合成元数据，不测试联网下载。
- 用同一签名身份在隔离目录原位替换 0.2.2 → 0.2.4，验证主应用及四个工具相互满足指定要求，数据库 inode 与排除规则保留。首次建检查点，后续同一开机周期重启按事件补停机期间的新增、改名和删除，没有进入全量遍历。未把签名验证当作真实系统隐私授权继承测试。
- 固定安装路径、一次迁移、回滚及普通运行期间拒绝覆盖见[升级说明](UPGRADING.md)。模型默认、能力上限和数据迁移见[离线 Gemma](offline-gemma.md)及[上一版核验](VERIFICATION-0.2.3.md)。
