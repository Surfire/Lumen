# Lumen 0.2.3 核验

- 37 项常规 Rust 与 CLI 检查、1 项真实 Gemma 集成、10 项扩展检查通过；格式与 Clippy 通过。签名 App 资源、菜单栏驻留、10 组隔离原生 GUI 测试通过，包括中英双向 Gemma、部分覆盖、搜索与 Finder 调用边界、启动访问核对前不展示旧索引。
- 在隔离目录让 0.2.2 和 0.2.3 使用同一安装路径及同一测试数据库。对真正不同的两个 App 构建，其外层及四个内置工具逐一做双向指定要求验证（5/5）。0.2.3 保留数据库 inode、既有结果和排除范围。第一次建立游标，之后重启补齐停机期间的改名、新增和删除，未进入全量遍历。自动安装测试另覆盖身份不匹配拒绝、临时签名迁移、运行中拒绝和回滚。
- 24 万文件合成库：旧版重启就绪中位数 1.472 秒；新版首核对 1.120 秒；随后五次同一开机周期重启中位数 0.081 秒，离线增删改名追平 0.089 秒。首次从旧库将有一次必要的基线核对；系统重启、事件记录缺失、访问或范围实际改变时仍会安全复核。不把合成速度当作真实全盘耗时。
- 官方固定 Q8_0 文本模型和 ARM64 llama.cpp 均校验，模型通过私有 Unix socket 在本机运行。共享合成 `fixed` 集中 Top 1：中文 BGE 25/30 → Gemma 30/30，英文 19/20 → 20/20；同主题无答案仍有误报，均只作相关片段。43,690 个合成向量、1,094 份合成文档下语义查询热 p95 82.9 毫秒，首次约 0.97 秒，不含 GUI。未加入图像、音视频语义模型。
- 签名一致性不等于已验证真实 macOS 目录授权继承。上述流程不修改系统授权，也不打开个人目录。从临时签名切换到固定身份的首次授权由 macOS 控制；独立的真实目录授权弹窗跨版验证不包含在当前测试里。

安装、签名和回滚见 [升级说明](UPGRADING.md)；模型与实际安装校验见 [离线 Gemma](offline-gemma.md)。
