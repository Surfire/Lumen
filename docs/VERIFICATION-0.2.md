# Lumen 0.2 验证记录

验证机器：Apple Silicon M5 Max，macOS 27.0.1。下列都是本机实验，不是跨机器性能保证。应用构建为本机签名包，测试未更改系统快捷键、Spotlight 设置或辅助功能权限。

## 搜索与日常操作

最终构建通过 28 项引擎测试、10 项扩展测试和 9 组签名原生 GUI 隔离测试，其中两组使用此机安装的真实中英文 BGE。搜索界面验证过暂停并继续后台语义索引、排除范围跨重启，以及文件同路径原子替换发生在旧片段首次显示前时拒绝该片段。

- 签名原生窗口的隔离冒烟覆盖首开、中英文、搜索框焦点、按键选中和回车、过期结果待回复时按回车不打开旧文件、AppKit 标记文本不误触发打开，以及基于真实 FSEvents 的合成文件增删。没有用实体热键跨应用，也没有驱动真实中文输入法候选窗。
- 引擎测试覆盖增删改名、正文变更、同名替换、重启补偿、目录丢失与恢复、权限暂时缺失、搜索缓存失效、排除路径的大小写别名及符号链接、TXT/MD/PDF/DOCX 范围和本地向量不混用。
- 真实 OneDrive 只读抽查各一个在线占位、已缓存文件。两份按名称检出，正文索引各跳过一次；系统离线标志、分配块与大小前后不变。没有读文件内容，亦非整个网盘或其他提供商验收。
- 扩展测试通过随包的本地宿主列出原版语法支持的限定命令，验证实际 HUD、Markdown 文本预览、显式复制意图和换包后旧快照拒绝。测试不覆盖 Raycast Store 或未经测试的第三方扩展。未读取或改动用户的剪贴板。
- 签名包本地 BGE 两种语言的发现验证通过；每种语言以两批写入合成片段，再用改写查到对应原文。语义只是相关原文候选，评估结果、误报和适用范围见[模型报告](offline-semantics.md)。

## 对照结果

| 比较 | 语料与关键结果 | 边界 |
|---|---|---|
| 新旧 Lumen 常驻索引 | 100 万合成文件。精确文件名 Top 1 p95 15.34→0.19 ms，常见前缀 Top 60 22.31→2.09 ms，高密度前缀 Top 60 205.32→18.87 ms | 不含窗口绘制。任意目录子串和拼音并无同样的收益 |
| Lumen / 旧 Luminator | 10 万合成文件，同机。Lumen stdio 与旧引擎 socket 的热态 p95：已知唯一 0.313 / 0.224 ms，宽词 0.081 / 1.132 ms；两边对应范围内都检出正确阳性 | Lumen 宽词快，但唯一词这一组慢；首建 3.665 / 0.510 秒。不是 Tinycast 界面或等排序 Top‑K 的全面对照 |
| Lumen CLI / Spotlight mdfind | 120 份合成文件全部被 Spotlight 收录；40 个精确名称查询均正确。p95 6.375 / 42.482 ms | 计启动命令到收到正确路径，不是全盘、文本或原生首帧对照 |

复现：`scripts/compare-luminator.py`、`scripts/compare-spotlight.py`、`scripts/benchmark.py`。Spotlight 必须先确认全部样本可查，等待未完成时不输出速度结果。

不宣称 Lumen 全面快过 Spotlight 或 Tinycast，也不把本机的合成样本误报率等同于真实文档表现。
