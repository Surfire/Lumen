# Lumen 0.2.6 核验

- 用 0.2.5 创建的独立索引重放多词、调序、连续或全角空格、带引号的连续短语、中文与拼音首字母混输，以及名称和已索引正文查询。新版直接读取旧库，文件字节不变。
- `成都 卫健委 pptx` 和 `卫健委 成都 .PPTX` 的有序结果一致。目录名带扩展名、正文提到扩展名、复合名称以 `.bak` 结尾不会误通过。引号内的扩展名作为文本匹配，不当筛选；有引号或扩展名筛选时不混入语义推荐。拼音沿用现有转写，多音字覆盖未改变。
- 120 万条旧版生成的合成库通过常驻协议验证：「鹿鸣」有序结果一致，p95 为 0.188 → 0.179 毫秒；多词带扩展名 p95 为 0.981 毫秒。这些是引擎测量，不是实盘端到端延迟。
- 原生启动器隔离测试覆盖无索引时搜索并实际启动一个合成应用、系统设置地址派发、隔离剪贴板、把本机快照交给原生 Quick Look。当前 macOS 的 13 个设置扩展标识均已与系统安装内容核对。未逐项在用户前台打开设置页或测 Finder 窗口绘制。
- 44 项常规 Rust/CLI、真实 Gemma CLI 和界面、10 项扩展、12 组原生界面场景、资源及签名通过。临时目录回归覆盖相同身份原位替换、回滚、签名不符、运行中拒绝及保留数据。验证未改实际 macOS 文件访问授权。
