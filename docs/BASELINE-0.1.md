# 0.1 本机合成基准

复现：`python3 scripts/benchmark.py --entries 100000`。Apple M5 Max / 128 GB，macOS 27.0.1，release arm64。脚本在隔离临时目录生成 100,000 个空文件、100 个子目录，用 Lumen 一次扫完 100,101 条（含根目录）。批量 API 覆盖 101 个目录，无 fallback。扫描建库 4,987 ms，SQLite 主文件 81,076,224 字节。无正文、模型或既有 Spotlight 索引参与。

热进程，通过原生窗口使用的 stdio JSON 接口测量从发出查询到收到结果。每组 72 样本，Top 20，每组先预热 6 个查询。数字不含真实窗口渲染、首次启动或 macOS 云盘开销。

| 查询组 | p50 | p95 | 最大 | 有命中次数 |
| --- | ---: | ---: | ---: | ---: |
| 有区分度的名称片段 | 0.109 ms | 0.167 ms | 0.213 ms | 72 / 72 |
| 热门词 / 高扇出路径 | 2.177 ms | 25.748 ms | 26.050 ms | 72 / 72 |
| 1–2 字短词 | 13.889 ms | 16.186 ms | 16.922 ms | 48 / 72（该组部分查询故意无匹配） |
| 无命中长词 | 0.037 ms | 0.054 ms | 0.071 ms | 0 / 72（预期） |

短词按当前实现扫描名称表，不能把精确命中的亚毫秒外推到所有查询。百万条、高频覆盖、内存、磁盘、更新与界面延迟仍须跑更广维度。此环境确认 Spotlight 服务停用，Tinycast 未进行同机器同语料同功能对照；**本结果不能证明 Lumen 超过 Spotlight 或 Tinycast。**

`scripts/smoke-app.py` 验证已构建应用的签名、PDFKit 对合成单页 PDF 的原文提取、GUI 使用的 Rust 查询接口、本地实际英语释义 Top 1（余弦 0.595），以及简体中文产生 640 维真向量。未启动原生窗口，没有读取或扫描任何用户文件。
