# 架构决策：先返回文件名，再补充正文和语义

本篇是目标设计；模块是逻辑边界，不要求每块拆成独立进程或 crate。首版可只用一个 Rust 进程与一个持久索引完成闭环。**不 fork Tinycast，不依赖运行中的 Luminator、Oil Find 或 DigUp，不使用 Spotlight 作为主要索引的隐形替代。**

```text
键盘启动器 / CLI / 已验证的扩展桥
              │ Search(query, scope, locale, request_id, limit)
              ▼
     查询协调器：分段返回、按文件去重、忽略过时查询
       ├─ 名称 / 路径 / 拼音  ←─ 热索引
       ├─ 中文及混合语言全文 ←─ 文档片段、位置、词项
       └─ 本地文本语义       ←─ 同模型版本的片段向量
                      ▲
卷发现 → 范围规则 → 元数据枚举 → 文件目录 / 变更队列
                        └─ 独立的安全读取闸门 → 提取 → 选做编码
```

### A. 扫描什么，拒绝什么

- 默认自动发现本机可访问的本地卷，从规范化根集合开始。没有白名单时不是“无目录”；配置白名单后则限制扫描范围，用户黑名单优先。系统伪卷、递归别名、外部网络挂载、应用私密索引与显式敏感位置不在普通默认扫描中，不因列表优先级意外重新纳入。维护拒绝原因计数，而非向用户展示其他账户的文件名。
- 不把 APFS 系统卷与 Data 视图重复计数；按卷身份区分挂载/卸载，保留展示路径，不把路径规范化当成跟随符号链接的授权。分别测试目录改名、包目录、符号链接循环、权限中途变化及重复路径。
- 先取廉价元数据，批量枚举，按预算并发；优先收录文件名、根目录名称和应用。可利用系统批量属性 API 做加速；先用同一数据集的基准证明确实优于简单遍历，再引入复杂优化。
- 文件身份设计采用卷 + 文件标识 + 可用的代际元信息；展示路径是成员关系，不能把两个硬链接误合成一个可打开的路径。事件通知用于调度，不能当成完整操作日志。[Apple FSEvents](https://developer.apple.com/documentation/coreservices/file_system_events) 丢失、目录掉线、游标失效后，对受影响范围重扫并按批次提交，不能将暂时不可读当作已删除。

### B. 为什么不触发云文件下载

名字与文件字节走不同入口。OneDrive、iCloud Drive 等采用 macOS [File Provider](https://developer.apple.com/documentation/fileprovider) 的目录，允许索引 OS 已公开的名字；没有提供商账号、私有 API 或后台“下载以便索引”。名字可见不是文件已下载的证明。

| 判断 | 枚举和结果 | 正文、预览、哈希、向量 |
|---|---|---|
| 可见的仅在线文件 | 保存名称与占位状态 | 禁止打开，不取缩略图，不令解析子进程另行打开 |
| 不能安全展开的目录 | 保存目录本身，并计覆盖缺口 | 不强制遍历，不猜测其子文件 |
| 确认本地且能阻止按需取回 | 可搜索名称 | 在大小、格式和权限预算内解析；云文件被逐出时立即退回仅名称 |
| 提供商状态未知，或系统保护不可用 | 可证明安全的元数据仍可索引 | **保守跳过**；不以路径名、文件大小、扩展名或“打开试试”推断可读 |

Darwin SDK 提供 `SF_DATALESS` 和禁止 dataless materialization 的 I/O policy。枚举与打开前检查属性，实际读取所在的进程/线程（含独立 helper）必须设置并验证保护；避免“检查时已缓存、打开时已被逐出”的竞态。文件描述符读取须防跟随符号链接、核对身份及上限。不能为未知供应商保证内核保护时，至少对其根采用仅名称策略。**不承诺本机没有同步客户端自身的通信；验收的是 Lumen 不发起文件内容取回。** 未枚举的远端全集不属于可验证覆盖。

### C. 从输入到结果

**名称。** 原路径用于打开，归一化键用于比较；为汉字词组保存全拼和首字母，保留不识别字符。多音字策略、繁简映射和分隔符策略分开测试。预先计算索引，避免每打一个字都做全盘转写。对搜索条件延长可以复用完整候选集，不能只筛上一屏 Top 10。

**全文。** 名称结果不等解析器。对本地且受支持的文件按格式提取原文；段落/真实页码随片段保存，支持中文中间词搜索。无文本层或解码失败时报告实际状态。文件内容变化或被排除时，过期片段和向量不可继续显示。内容索引留在用户私有应用目录，不提交、不遥测。

**文本语义。** 提供嵌入器接口，记录模型标识、revision、语言、维度和规范化方式；只比较同一空间的向量。Apple 系统语义能力或另行取得的本地模型均可适配，优先选能在目标语言真正得到向量的实现；不可用则明确降级。演示时不得用子串匹配、词袋或硬编码同义词冒充模型。没有配对质量评测前不要声称“懂任意中文”。先做正确的精确向量基线，规模和实测有需要再引入 ANN。

**融合。** 文件名精确与首字母命中、正文逐字命中、语义相关各保留来源，展示时一个文件可携带多类证据。精确的编号不应被语义弱命中压下。查询 ID 防止慢结果覆盖新输入；名称先回，后来的片段不抢走用户当前选中项。路径变化时打开前重新解析；错误明确，不伪装成零结果。

### D. 更新、后台运行与隐私

优先级：用户正在输入 > 返回结果/打开 > 元数据更新 > 正文 > 向量。写入批量提交；读取使用一致的已提交视图。失败队列有原因、重试和退避；接受任务不代表完成。索引包含私人路径和正文，持久化目录和 socket 只给当前用户；只允许同用户本地通信。不在首版注册登录项、修改现有 Spotlight 快捷键或请求新增系统权限。真正提供这类功能时使用显式设置与可恢复操作。构建不默认下载模型、执行扩展安装脚本、启动全盘扫描或读取开发者个人资料。

### E. 可替换的边界

保留纯 Rust 查询和 CLI；macOS 代码限于卷枚举、文件状态、文件提取与本地推理、热键及界面。跨 FFI 传可验证的边界值和错误，测试可注入虚拟提供商/嵌入器。macOS API 的小型原生桥不等于把参考工程源码嵌入 Lumen。扩展宿主与索引权限分开；扩展不能因为是“生态插件”就取得全盘正文、shell 或网络能力。
