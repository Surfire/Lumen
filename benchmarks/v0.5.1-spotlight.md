# v0.5.1 Spotlight vs. Lumen Comparison Benchmark

Measured 2026-11-27 on **Apple M5 Max, 128 GiB RAM, macOS 27.0.1**, commit `81385f7`, `target/release/lumen` (`rustc 1.96.0`, locked release build).

## Methodology & Fairness Scope

Following [docs/BENCHMARK.md](../docs/BENCHMARK.md):

1. **Public Verified Corpus**: Both Spotlight (`mdfind -onlyin`) and Lumen indexed the exact same open-source workspace tree (`src/`, `app/`, `docs/`, `scripts/`, `benchmarks/`, `packaging/` — `110` items total, `14.54 ms` initial Lumen scan into an isolated `/tmp` database; `0` private files read).
2. **Pre-Timing Coverage Gate**: 50 unique filenames were verified to return the exact matching path in **both** `mdfind` and `lumen` before timing began.
3. **Interleaved Multi-Layer Sampling**: Each of the 50 queries was executed 3 times in shuffled order (**150 samples per layer**), alternating execution order (`lumen` vs `mdfind` first) and asserting exact path correctness on every response:
   - **Same-layer CLI**: Cold subprocess invocation per query (`lumen query --mode name -- <name>` vs `/usr/bin/mdfind -onlyin ... 'kMDItemFSName == "<name>"cd'`).
   - **Persistent Daemon Layer (Reported Separately)**: Hot JSONL stdio daemon (`lumen serve`, matching how the macOS app talks to the engine after startup), plus measured `ps -o rss=`. **Never compared 1:1 as if both were cold CLI launches.**

## Measured Results (50 Distinct Files × 3 Passes = 150 Queries/Layer)

| Engine & Layer | Samples | p50 (ms) | p95 (ms) | p99 (ms) | Max (ms) | Notes |
| :--- | ---: | ---: | ---: | ---: | ---: | :--- |
| **Spotlight (`mdfind` CLI)** | 150 | 42.782 | 46.508 | 50.077 | 60.000 | Same-layer OS metadata CLI query |
| **Lumen (`lumen query` CLI)** | 150 | **6.431** | **7.756** | **9.902** | **10.127** | Same-layer cold CLI (**6.00x faster p95**) |
| **Lumen (`lumen serve` Daemon)** | 150 | **0.013** | **0.031** | **0.057** | **0.078** | Warm JSONL stdio daemon (`10,848 KiB` / `10.59 MiB` RSS) |

> On newly created temporary directories in local tests (`scripts/compare-spotlight.py --entries 120`), macOS Spotlight `mds` reported `Spotlight_not_fully_ready` (`metadata_matches: 0` within 50s) because background OS ingestion is asynchronous, whereas Lumen finished full indexing of the repo tree in **14.54 ms** (and **45.50 s** for 1,000,000 APFS files in [v0.4-baseline.md](v0.4-baseline.md)).
