# Lumen：一个搜索框，找回 Mac 上的东西

**产品目标，不是当前构建的功能清单。** Lumen 面向 Apple Silicon Mac，默认从使用者有权访问的本机范围中搜索，不要求先选一个资料夹。不是 Spotlight 插件，不改写系统快捷键、关闭系统索引或接管别人的网盘客户端。首版实装范围看根目录 README；规划中的能力不等于发布承诺。

## 三个使用场景

| 我记得什么 | 怎么搜 | 怎样才算找对 |
|---|---|---|
| 大致文件名或其读音 | 输入“青山月报”、全拼或首字母；结果边输入边出 | 排在前面的应是同名文件或文件夹，不是正文里碰巧出现的词；根目录也可命中 |
| 明确的文档内容 | 搜“冷库库存复核”，即使文件名是“会议记录” | 标出正文片段；有真实页码才展示页码；同文件多处命中不霸屏 |
| 只记得意思 | 搜“怎样让新同事尽快上手”，目标文件却叫“入职伙伴手册” | 就地返回相关文件和原文片段。标为“语义相关”，不假装逐字命中，不替用户生成答案 |

另一个常见场景是找回只在线保存的文件。能看到名字，就让它能被名称、拼音和路径找到，并显示“仅在线”；不能看到的目录不得报成空目录。用户主动选择在 Finder 中打开文件，才由系统和云盘决定是否下载。索引、预览、排序都不是下载许可。

## 从第一次打开到日常使用

1. **第一次使用。** 默认范围为本机可访问的本地卷，不要求先配置多个根；显示“正在建立索引，已找到 … 项”。名称先可用，后续工作不挡输入。支持的网盘目录自动纳入。遇到权限限制，解释缺口，不循环索取权限。
2. **搜索。** 主搜索混合应用/命令（启动器阶段）、文件和目录。每个结果注明命中类型、足以区分同名项的路径、云端状态；回车打开、定位到 Finder、复制路径分别是不同动作。未命中、索引未完成、无权限、后端失联四种情况分开显示。
3. **选择范围。** 可以限制为若干目录，也可以保持全盘只排除部分目录。新增排除应立即阻止该范围的新读取及结果展示，后台清理旧索引；不得把排除仅做成 UI 隐藏。默认不跟随符号链接、不跨入网络挂载、系统伪卷或重复 APFS 视图；“全盘”不代表越过这些边界。
4. **分层开关。** 名称索引无需模型。全文和文本语义可以分别暂停；语义不可用时，名称和全文仍工作。预期使用本地文本模型或系统的本地能力；首次下载独立模型时，应说明体积、许可并由用户选择，不把本机内容送往云服务。
5. **资源。** 优先交互；后台任务按可中断小批执行。允许暂停并在重启后续建。进度区分已枚举、可读、已抽取、已编码、跳过与错误；“进度 100%”不能掩盖占位目录或权限缺口。

## 语言和扩展

首版交互目标为简体中文和英语：应用文案、错误、设置、索引状态都可切换；未支持地区回退，不根据界面语言改变已建索引。中文文件无论中英文界面都须能按汉字、全拼、首字母检索。路径和文件名保持原样。开发接口的字段和错误码保持稳定，不翻译。

支持 Raycast 扩展指 **Lumen 当宿主运行经验证的命令**，不仅是给 Raycast 写一个 Lumen 命令。先列出可识别格式，再一类一类验证运行能力；未支持的扩展必须说明原因。详见 [兼容边界](COMPATIBILITY.md)。

## 交付顺序与放行条件

- **可体验内核**：以无私人数据的样本完成“扫描→查询→展示来源→变化后更新”闭环；中文与英文、拼音、范围拒绝及仅在线文件都有测试。每种尚未提供的能力在 README 标明。
- **日常可用的启动器**：热键唤起、中文输入法组字、键盘导航、取消过期查询、错误恢复、索引持久化和文件变更，均从实际入口验证。CLI 结果不能替代这一级。
- **语义与扩展验收**：用无明显共享词仍相关的文档验证文本语义；用独立扩展而非只有 manifest 的样本验证宿主。完整门槛见 [性能与质量协议](BENCHMARK.md)。

图片语义、扫描件 OCR、全能助手、自动整理/移动/删除用户文件、绕过云盘权限或导出私人索引，不在首版范围。
