# Lumen 0.2.5 核验

- 两个汉字的常见名称查询从已有 FTS 词项取候选，并用小型尾缀索引补漏，不再默认扫全库。候选过多时保留完整慢路径，不截断结果或改变排序。名称和正文分开返回，正文索引为空时跳过正文查询。
- 同一台 Mac，240 万条合成记录、78 种查询各两轮，新旧有序结果一致。新版文件名精确／前缀／中缀／尾缀／路径无正文项的热 p95 分别为 0.35／2.32／0.34／0.34／0.50 毫秒；旧版分别为 1642／1501／1875／1645／1603 毫秒。高频词触发完整查询时仍可能约 1 秒。一份约 334 万条合成库的「鹿鸣」首条引擎回复为 574.5 → 16.8 毫秒，属于合成工作负载，不等同于实盘或 Finder 窗口耗时。
- 回车和 ⌘↩ 对当前名称与正文命中只校验所选路径，而非重新搜索整个目录；保留范围、符号链接、可见性、云盘占位和文档指纹检查。单路径 CLI 校验进程级中位数约 6 毫秒；包含离屏 UI、校验和派发的 ⌘↩ 合成测试为 71.8 毫秒，止于 Finder 调用回调，不含 Finder 绘制或云盘交互。语义候选仍按原查询复核。
- 43 项 Rust/CLI 常规、真实 Gemma 集成、10 项扩展、11 组隔离 GUI、签名、启动及资源检查通过。升级从已有数据库补建尾缀索引；不需要丢弃原有库或重新遍历整棵目录。真实系统目录授权在本轮未编程改动。

更多边界见 [升级说明](UPGRADING.md) 与 [0.2.4 核验](VERIFICATION-0.2.4.md)。
